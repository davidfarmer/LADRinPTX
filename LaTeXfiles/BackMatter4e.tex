\chapter{Colophon: Notes~on~Typesetting}

\vspace{-5.5bp}

\begin{Itemize}

\item
This book was typeset in Lua\LaTeX\ by the author, who wrote the \LaTeX\ code to implement the book's design.

\item
The \LaTeX\ software used for this book was written by Leslie Lamport. The \TeX\ software, which forms the base for \LaTeX, was written by Donald Knuth.

\item
The main text font in this book is the Open Type Format  version of \TeX\ Gyre Termes, a font based on Times,
which was designed by Stanley Morison and Victor Lardent for the British newspaper \emph{The Times} in 1931.

\item
The main math font in this book is the Open Type Format version of \TeX\ Gyre Pagella Math, a font based on Palatino, which was designed by Hermann Zapf.

\item
The sans serif font used for page headings and some other design elements is the Open Type Format version of \TeX\ Gyre Heros, a font based on Helvetica, which was designed by Max Miedinger and Eduard Hoffmann.

\item
The Lua\LaTeX\ packages \textsf{fontspec} and \textsf{unicode-math}, both written by Will Robertson, were used to manage fonts.

\item
The \LaTeX\ package \textsf{fontsize}, written by Ivan Valbusa, was used to gracefully change the main fonts to 10.5 point size.

\item
The figures in the book were produced by \textit{Mathematica}, using \textit{Mathematica} code written by the author. \textit{Mathematica} was created by Stephen Wolfram.
The \textit{Mathematica} package \textsf{MaTeX}, written by Szabolcs Horv\'at, was used to place \LaTeX-generated labels in the \textit{Mathematica} figures.

\item
The \LaTeX\ package \textsf{graphicx}, written by David Carlisle and Sebastian Rahtz, was used to include photos  and figures.

\item
The \LaTeX\ package \textsf{multicol}, written by Frank Mittelbach, was used to get around \LaTeX's limitation that two-column format must start on a new page (needed for the Symbol Index and the Index).

\item
The \LaTeX\ packages \textsf{Ti\textit{k}Z}, written by Till Tantau, and \textsf{tcolorbox}, written by Thomas Sturm, were used to produce the definition boxes and result boxes.

\item
The \LaTeX\ package \textsf{color}, written by David Carlisle, was used to add appropriate color to various design elements.

\item
The \LaTeX\ package \textsf{wrapfig}, written by Donald Arseneau, was used to wrap text around the comment boxes.

\item
The \LaTeX\ package \textsf{microtype}, written by Robert Schlicht, was used to reduce hyphenation and produce more pleasing right justification.

\end{Itemize}
